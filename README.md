# Data-Engineering-Project

Учебный проект по предмету «Инжиниринг управления данными»

**Автор:** Полина Симанина

## Датасет

**Название:** Finance Ecommerce Dirty Dataset

**Описание:** Датасет содержит данные о финансовых транзакциях в электронной коммерции. Данные содержат пропуски, дубликаты, некорректные значения и несогласованные форматы, что позволяет использовать их для задач очистки и подготовки данных.

**Размер:** 6060 строк × 23 столбца, 1.23 МБ

**Формат:** CSV

**Ссылка на датасет:** https://drive.google.com/file/d/1Xk2KMJSVp_JmmAD-3fYD2w8qVVBaelJJ/view

## Запуск проекта

1. Убедитесь, что 'uv' установлен

2. Установите зависимости проекта:

```bash
uv sync --frozen
```

3. Запустите скрипт:

```bash
uv run python data_loader.py
```
При запуске датасет скачивается с Google Drive в папку `data`, далее в консоль выводятся первые 10 строк.

## Загрузка данных в базу

Установить зависимости проекта:

```bash
uv sync
```

Создать в корне проекта файл `.env` с параметрами подключения к базе данных:

```text
DB_USER=
DB_PASSWORD=
DB_URL=
DB_PORT=
DB_ROOT_BASE=
```

Запустить скрипт загрузки данных в базу:

```bash
uv run python scripts/write_to_db.py
```

Скрипт загружает 100 строк из файла `data/finance_ecommerce_typed.parquet` в PostgreSQL.
