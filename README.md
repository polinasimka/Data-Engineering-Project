## Датасет

**Название:** Finance Ecommerce Dirty Dataset

**Описание:** Датасет содержит данные о финансовых транзакциях в электронной коммерции. Данные содержат пропуски, дубликаты, некорректные значения и несогласованные форматы, что позволяет использовать их для задач очистки и подготовки данных.

**Размер:** 6060 строк × 23 столбца

**Формат:** CSV

**Ссылка на датасет:** https://drive.google.com/file/d/1Xk2KMJSVp_JmmAD-3fYD2w8qVVBaelJJ/view
