# Data-Engineering-Project

Учебный проект по предмету «Инжиниринг управления данными».

Автор: Полина Симанина.

Проект включает исследование датасета и ETL-пакет: скачивание исходных данных, преобразование типов, сохранение в Parquet и загрузку первых 100 строк в PostgreSQL.

## Датасет

**Название:** Finance Ecommerce Dirty Dataset.

Датасет содержит данные о финансовых транзакциях в электронной коммерции: суммы операций, валюты, сведения о клиентах и продавцах. В данных встречаются пропуски, дубликаты, некорректные значения и разные форматы дат.

- Размер: 6060 строк и 23 столбца.
- Исходный формат: CSV.
- [Ссылка на датасет](https://drive.google.com/file/d/1Xk2KMJSVp_JmmAD-3fYD2w8qVVBaelJJ/view).

## Этапы ETL

### 1. Получение данных

Модуль `extract.py` создаёт папку `data` и скачивает CSV с Google Drive, если файла ещё нет. Затем читает его в DataFrame и выводит первые строки в терминал.

Если CSV уже существует, используется локальный файл.

### 2. Преобразование данных

Модуль `transform.py` приводит выбранные столбцы к нужным типам:

| Столбцы | Тип после преобразования |
| --- | --- |
| `Date`, `CustomerSince` | Дата и время |
| `Amount`, `Balance` | Числовой |
| `MerchantPhone`, `PostalCode`, `Phone` | Строковый |

Значения дат и чисел, которые не удалось преобразовать, становятся пропусками. В терминал выводятся типы столбцов и общее количество пропусков в `Date`, `CustomerSince`, `Amount` и `Balance` после преобразования.

Результат сохраняется в файл:

`data/finance_ecommerce_typed.parquet`

### 3. Загрузка в базу данных

Модуль `load.py` читает подготовленный Parquet и записывает первые 100 строк в таблицу `simaninapa` в PostgreSQL.

При повторном запуске таблица заменяется. Строки не добавляются к предыдущей загрузке.

## Подготовка к запуску

Для работы нужны Python 3.11 или новее, установленный `uv` и доступ к PostgreSQL.

Все команды выполняются из корня проекта — папки, в которой находится `pyproject.toml`.

### Установка зависимостей

```powershell
uv sync --locked
```

Команда создаёт окружение проекта, устанавливает зависимости из `uv.lock` и пакет `etl`.

Основные зависимости:

- `gdown` — скачивание файла с Google Drive;
- `pandas` — чтение и обработка данных;
- `pyarrow` — работа с Parquet;
- `sqlalchemy` и `psycopg2-binary` — работа с PostgreSQL;
- `python-dotenv` — чтение настроек подключения из `.env`.

В группе `dev` находятся `ipykernel`, `seaborn` и `requests`: они используются для ноутбуков, визуализаций и отдельного скрипта работы с API.

### Настройка подключения к PostgreSQL

Создайте в корне проекта файл `.env` и заполните параметры:

```dotenv
DB_USER=
DB_PASSWORD=
DB_URL=
DB_PORT=
DB_ROOT_BASE=
```

## Запуск ETL

Запуск всех этапов:

```powershell
uv run python -m etl.main
```

По умолчанию в терминал выводятся первые 10 строк исходного датасета.

Чтобы изменить количество строк для просмотра:

```powershell
uv run python -m etl.main --preview 5
```

Параметр `--preview` управляет только выводом исходных данных в терминал. При этом преобразуется весь датасет, а в PostgreSQL загружаются первые 100 строк.

Справка по параметрам:

```powershell
uv run python -m etl.main --help
```

## Результат запуска

После успешного выполнения:

- исходный CSV находится в `data/finance_ecommerce_dirty_dataset.csv`;
- данные с преобразованными типами сохранены в `data/finance_ecommerce_typed.parquet`;
- в таблицу `simaninapa` записаны первые 100 строк;
- в терминале выведено сообщение `Rows written: 100`.
